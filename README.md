## ✨ Sobre o Projeto

Moviio é um CRM imobiliário desenvolvido para ajudar corretores e imobiliárias a centralizarem toda a operação comercial em uma única plataforma.

O sistema foi criado para eliminar planilhas, reduzir perda de leads e aumentar a taxa de conversão através de um funil de vendas moderno e intuitivo.
